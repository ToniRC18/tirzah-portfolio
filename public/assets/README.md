# Assets del portafolio — Tirzah S. Kook

## Cómo agregar archivos

1. Guarda el archivo con el nombre exacto indicado en el placeholder
2. Colócalo en la carpeta correspondiente
3. Cambia `ruta: "PENDIENTE"` por la ruta real en el archivo de datos
4. Corre `npm run build` para verificar

## Convención de nombres
[portafolio]-[sección]-[slug].[ext]
Ejemplo: p1-academico-proyecto-integrador-1.pdf
